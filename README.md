# SeDePC

Official repository for **SeDePC: Semantic -Decoupled Privacy-Preserving Compression of Multi-Images with Invisible Feature Embedding**.

**Authors:** Yonghao Chen, Wenhan Yang, and Changxing Ding  
**Accepted at:** TCSVT

## Overview

This work proposes an algorithm that balances transmission efficiency, machine analytics performance, and privacy protection for edge–cloud systems. 
It combines image steganography and image coding for machine, optimizing cover image fidelity, latent entropy, and semantic embedding to balance visual concealment and task utility. 
Experiments show near-original classification accuracy and competitive retrieval and captioning performance at selected operating points.
